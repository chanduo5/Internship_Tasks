## 📌 About This Repository

This repository documents my hands-on journey through the **DevOps Internship Program** at **Davine Technologies** (Information Technology department, Remote). It's a weekly, task-based log of everything I'm learning and building — from Linux fundamentals to CI/CD pipelines, containerization, and cloud infrastructure.
